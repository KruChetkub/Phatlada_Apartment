# นโยบายคุกกี้และเทคโนโลยีการจัดเก็บข้อมูล (Cookie Policy)
**เว็บไซต์และระบบบริหารจัดการหอพักภัทร์ลดา อพาร์ตเมนต์ (Phatlada Apartment)**

**วันที่มีผลบังคับใช้:** 19 กันยายน 2569  
**เวอร์ชัน:** 1.0

---

## 1. คุกกี้และเทคโนโลยีจัดเก็บข้อมูลคืออะไร?
คุกกี้ (Cookies) และเทคโนโลยีจัดเก็บข้อมูลบนเบราว์เซอร์ (Web Storage เช่น LocalStorage / SessionStorage) คือไฟล์ข้อมูลขนาดเล็กที่ถูกจัดเก็บบนอุปกรณ์ของท่านเมื่อท่านเข้าชมเว็บไซต์ เพื่อให้เว็บไซต์สามารถทำงานได้อย่างมีประสิทธิภาพ จดจำการตั้งค่า และอำนวยความสะดวกในการใช้งาน

---

## 2. ประเภทของคุกกี้และพื้นที่จัดเก็บข้อมูลที่เราใช้งาน

เราใช้เทคโนโลยีการจัดเก็บข้อมูลในระบบดังต่อไปนี้:

### 2.1 คุกกี้และพื้นที่จัดเก็บที่มีความจำเป็นอย่างยิ่ง (Strictly Necessary Storage)
เทคโนโลยีเหล่านี้จำเป็นต่อการทำงานพื้นฐานของระบบ หากไม่มีส่วนนี้ระบบจะไม่สามารถให้บริการได้:
- **Authentication Session:** ใช้จดจำสถานะการเข้าสู่ระบบอย่างปลอดภัย และตรวจสอบบทบาทการเข้าถึงของผู้ใช้ (`OWNER`, `MANAGER`, `STAFF`)
- **Security Tokens:** ป้องกันการโจมตีทางไซเบอร์ เช่น Cross-Site Request Forgery (CSRF)
- **Active Dormitory ID:** จดจำหอพักปัจจุบันที่ผู้ดูแลระบบกำลังจัดการ

### 2.2 คุกกี้และพื้นที่จัดเก็บเพื่อการทำงานของระบบ (Functional Storage)
ใช้เพื่อจดจำการปรับแต่งและความชอบของท่าน:
- **UI Preferences:** จดจำการแสดงผลแถบเมนู (Sidebar toggle), สถานะการกรองข้อมูลห้องพัก
- **Thai Buddhist Era Format Settings:** จดจำการตั้งค่าการแสดงผลวันที่ พ.ศ. และรูปแบบรายงาน

### 2.3 คุกกี้เพื่อการวิเคราะห์และประสิทธิภาพ (Analytics Storage - ถ้ามี)
- ใช้รวบรวมสถิติการเข้าชมหน้า Landing Page เช่น จำนวนผู้เข้าชม เพื่อนำไปพัฒนาและปรับปรุงเว็บไซต์ (ข้อมูลจะถูกจัดเก็บแบบไม่ระบุตัวตน - Anonymous)

## 3. สรุปรายการเทคโนโลยีจัดเก็บข้อมูลที่ใช้งาน

| ชื่อ Key / คุกกี้ | ประเภท | วัตถุประสงค์ | ระยะเวลาจัดเก็บ |
| :--- | :---: | :--- | :---: |
| `phatlada_auth_logged_in` | จำเป็น (Secure) | บันทึกสถานะการล็อกอิน | จนกว่าจะออกจากระบบ |
| `phatlada_current_user_role` | จำเป็น (Secure) | บันทึกระดับสิทธิ์ผู้ใช้ | จนกว่าจะออกจากระบบ |
| `phatlada_active_dorm_id` | จำเป็น | บันทึกหอพักที่กำลังทำงาน | ถาวรบนเบราว์เซอร์ |
| `phatlada_cookie_consent` | จำเป็น | บันทึกการยอมรับนโยบายคุกกี้ | 1 ปี |

---

## 4. การจัดการและตั้งค่าคุกกี้
- ท่านสามารถตั้งค่าการยอมรับหรือปฏิเสธคุกกี้ที่ไม่จำเป็นได้ผ่าน **แถบยินยอมคุกกี้ (Cookie Consent Banner)** บนหน้าเว็บไซต์
- ท่านสามารถลบหรือปฏิเสธคุกกี้ทั้งหมดได้ผ่านการตั้งค่าเบราว์เซอร์ของท่าน (เช่น Chrome, Safari, Edge) ทั้งนี้การปิดคุกกี้ที่จำเป็นอาจส่งผลให้ไม่สามารถเข้าสู่ระบบหรือใช้งานบางฟังก์ชันได้

---

## 5. การปรับปรุงนโยบายคุกกี้
เราอาจทำการปรับปรุงนโยบายคุกกี้นี้เป็นครั้งคราวเพื่อให้สอดคล้องกับเทคโนโลยีและข้อกำหนดทางกฎหมาย โดยจะแจ้งวันที่ปรับปรุงล่าสุดไว้ด้านบนของหน้านี้
